3. ¿Cómo funciona?

  1. Identifica términos relevantes en la pregunta.
  2. Compara esos términos con cinco temas configurados.
  3. Muestra una respuesta preparada para el tema coincidente.
  4. Indica una fuente oficial para verificar la información.
  5. Si no encuentra coincidencias suficientes, se abstiene de responder.
